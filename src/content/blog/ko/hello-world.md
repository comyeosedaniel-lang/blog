이 글은 **예시 글**이에요. 실제로 글을 쓰기 시작하면 이 파일은 지우거나 자유롭게 덮어써도 됩니다.

## 새 글 쓰는 법

`src/content/blog/ko/` 폴더에 마크다운(`.md`) 파일을 하나 추가하면 그게 바로 새 글이에요. 파일 맨 위에는 이렇게 프런트매터를 적어주세요.

```md
---
title: 글 제목
description: 목록과 검색엔진에 노출될 한두 줄 요약
pubDate: 2026-07-25
tags: [태그1, 태그2]
draft: false
---
```

- `draft: true`로 두면 배포된 사이트에는 보이지 않고, 로컬 개발 서버(`npm run dev`)에서만 보여요.
- `tags`와 `updatedDate`는 선택 사항이에요.

## 마크다운 요소 미리보기

인용구는 이렇게:

> 쓰고 싶은 문장을 먼저 쓰고, 다듬는 건 나중에.

목록도 되고,

1. 순서가 있는 목록
2. 두 번째 항목
3. 세 번째 항목

코드도 됩니다.

```js
function hello() {
  console.log('안녕, mylineal');
}
```

준비되면 이 예시 글을 지우고, 첫 진짜 글을 시작해보세요.
